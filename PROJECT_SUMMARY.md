# Project Tracking System - Resume Summary

## Project Overview
**Project Tracking & Management System** - A full-stack web application for managing projects, tasks, employees, and team collaboration with role-based access control.

---

### Frontend Technologies:
- **React 18.2.0** - Modern UI library for building interactive user interfaces
- **React Router DOM 6.3.0** - Client-side routing and navigation
- **Tailwind CSS 3.3.0** - Utility-first CSS framework for responsive design
- **Axios 1.4.0** - HTTP client for API communication
- **React Hook Form 7.44.3** - Form state management and validation
- **Recharts 2.6.2** - Data visualization and charting library

## Project Purpose & Motivation

### Why I Built This Project:
I developed this project tracking system to solve real-world challenges in project management and team collaboration. The system addresses the need for:

1. **Centralized Project Management** - A single platform to track multiple projects, their status, budgets, timelines, and team assignments
2. **Task Organization** - Efficient task assignment, tracking, and progress monitoring for team members
3. **Role-Based Access Control** - Secure system with different permission levels for Admins, Project Managers, and Employees
4. **Team Collaboration** - Streamlined communication and coordination between team members working on shared projects
5. **Data-Driven Insights** - Dashboard with analytics and visualizations to monitor project health and team performance

### Key Problems Solved:
- **Visibility**: Provides clear visibility into project status, task assignments, and team workload
- **Accountability**: Tracks task ownership, deadlines, and progress for better accountability
- **Efficiency**: Reduces manual coordination efforts through automated workflows
- **Security**: Implements role-based permissions ensuring users only access relevant information
- **Scalability**: Designed to handle multiple projects and teams simultaneously

## Key Features Implemented

### 1. **Authentication & Authorization**
- User registration and login system
- JWT-based authentication
- Role-based access control (Admin, Project Manager, Employee)
- Protected routes and permission-based UI rendering

### 2. **Project Management**
- Create, read, update, and delete projects
- Project status tracking (Planning, In Progress, Completed, On Hold, Cancelled)
- Priority levels (Low, Medium, High, Critical)
- Budget tracking and timeline management
- Team member assignment with roles
- Project tags and categorization
- Advanced filtering and search functionality

### 3. **Task Management**
- Task creation and assignment to team members
- Task status workflow (Pending, In Progress, Completed, Cancelled)
- Priority management
- Due date tracking with overdue indicators
- Progress tracking with percentage completion
- Estimated hours tracking
- Task filtering by status, priority, project, and search

### 4. **Employee Management**
- Employee profile management
- Team member assignment to projects
- Role assignment within projects
- Employee activity tracking

### 5. **Dashboard & Analytics**
- Role-specific dashboard views
- Real-time statistics (projects, tasks, employees)
- Data visualization with pie charts (Recharts)
- Recent tasks and projects display
- Task status distribution visualization

### 6. **User Experience**
- Responsive design (mobile, tablet, desktop)
- Modern UI with Tailwind CSS
- Toast notifications for user feedback
- Loading states and error handling
- Modal-based forms for create/edit operations
- Intuitive navigation and layout
